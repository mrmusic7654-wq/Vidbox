# Vidbox — Infographics-Style Video Package

A full reconstruction of **The Infographics Show's** format (analyzed from
["This is What 'Always' Happens Before a Market Crash"](https://youtu.be/EOXle1B_dZs)),
applied to a brand-new story.

## The new video
**"This Is What 'Always' Happens Right Before a Bank Collapse"** — ~15 min explainer,
13 chapters + cold open, written beat-for-beat in the channel's narration style,
with original flat-vector visuals generated in its exact visual language.

## Contents
| File | What it is |
|---|---|
| `01_STYLE_ANALYSIS.md` | Deep deconstruction of the source video: narration DNA, visual system, motion grammar, replicable formula |
| `02_NEW_STORY_SCRIPT.md` | Full new script (cold open + 13 chapters), YouTube description block, production notes |
| `03_narration_plain.txt` | Narration text only (2,514 words ≈ 15.7 min @160 wpm) |
| `04_VISUAL_STORYBOARD.md` | Scene map, motion grammar, shot lists |
| `visuals/` | 10 flat-vector scene illustrations + thumbnail (AI-generated in style) |
| `audio/` | Narration VO clips, part00–part09 (voice-00) |

## Fact base
All statistics in the script come from public reporting: FDIC Quarterly Banking Profile &
Failed Bank List, Florida Atlantic University CRE screener, NBER working paper on CRE losses,
FT/Reuters/AP/Business Insider coverage of SVB, First Republic, Credit Suisse, and Berkshire
Hathaway 13F filings 2024–2026. Full source list in the description block of the script.
